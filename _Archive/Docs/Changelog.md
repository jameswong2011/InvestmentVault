## 2026-07-09 — Round-2 wrong-result fixes (H1–H9, stage 7)

Full findings: [[_Archive/Docs/2026-07-09 - Skills Audit Round 2 - Execution Test Report]] §3. The nine HIGH-severity wrong-result defects, all execution-verified after fix:

- **H1 /graph lock**: replaced the hand-rolled inline lock (no `timeout_at:`, no `.vault-lock.*` scan, no noclobber) with the standard preflight §1.3a block — a live `/graph` run was being classified STALE by every other skill's collision loop (`[[ "" > now ]]` false) and invited force-unlock. Added `sed` to graph allowed-tools.
- **H2 /transcript + /numbers FMP key**: `API_KEY=$(grep … | sed -E 's/…\s…/')` relied on GNU `\s` (BSD/macOS sed unsupported) → returned the whole JSON line, passed the `-z` guard, then every curl exited rc=3. Both skills now use `jq -r '.fmp_api_key // empty'`. Also fixed the transcript dates-endpoint parse (`fiscalYear`, not `year`).
- **H3 verify_note.py #1**: dropped the `"—" in val` disjunct from the PyYAML-absent heuristic — an em-dash in an unquoted scalar is valid YAML, but the heuristic (the live path, PyYAML not installed) false-BLOCKed and in url/pdf mode deleted good notes (e.g. `sector: Semiconductors — Cross-sector …`). Verified: 2802 comparison now ADVISORY not BLOCK.
- **H4 verify_note.py #4**: mid-sentence check scanned only `[A-Za-z']` tokens, so `…in 2026."` resolved its "last word" to the stopword "in" and false-BLOCKed. Now short-circuits when the final char is a terminal (`.!?"')]`). Verified: DRAM HBM deep-dive PASSes; a genuinely truncated control still BLOCKs.
- **H5 /rename patterns**: replaced the 7-pattern enumeration (missed `.md#anchor`, `.md|alias`, folder-less `.md` forms — 18 escaped-pipe + 2 anchor links exposed) with a STEM prefix-rewrite (`[[Theses/TICKER - old_name` / `[[TICKER - old_name` at the `{ ] . # | }` boundary set) that preserves every suffix by construction. Aligned `wikilink-forms.md` FOLDER enumeration (`Macro` → `Macro & Technology`, the P1.1 site Stage-2 missed).
- **H6 /thesis archive-collision**: Signals A/B were non-recursive and scalar-ticker-only → missed the one real archived thesis (`_Archive/Theses/SEMICAP`, `ticker: [KLAC, …]`, `status: archived`). Now: recursive glob, list-form + archived-status grep, and a new Signal E (tags). Verified: `/thesis KLAC` catches SEMICAP via B + E; negative control clean.
- **H7 /numbers + /transcript foreign tickers**: (a) `parse_old_numeric` stripped thousands-commas before the numeric regex (`¥35,950` was → 35.0, now 35950.0; `₹10,000 crore` → 10000.0); currency regex gained `₹/NT$/INR/crore/lakh`; `_fmt_suffix` no longer misreads the `T` in `NT$` as Trillion. (b) FMP-symbol catch-22 fixed via a new optional `fmp_symbol:` frontmatter field (API skills prefer it, fall back to `ticker:`, never the filename) — set on 5 theses (2383→2383.TW, 6981→6981.T, GAW→GAW.L, 5332→5332.T, AIXA→AIXA.DE); `ticker:` left untouched so lint/graph/matching are unaffected.
- **H8 /surface**: (a) read-budget — sector notes are now section-targeted via `extract_sections.py` (50 sectors × full = 445K words alone exceeded subagent context; the "~13 files in full" count was stale ~4×); scale constants corrected (76 theses / 50 sectors / 8-9 macros; `all` mode flagged as ~960K words, full-read-only). (b) sector-scope resolution routed through `_shared/sector-resolution.md` (case-insensitive — the skill's own example `/surface semiconductors` had resolved to 0 matches); no-match behavior defined; added the adjacency-miss/glob-hit branch so `/surface CBRS` (thesis newer than the graph) resolves from disk instead of failing.
